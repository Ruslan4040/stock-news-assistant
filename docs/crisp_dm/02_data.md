## 2026-11-14 — Download scripts and data cards
- What was done:
  - `src/data/download.py` gets prices (yfinance), PhraseBank (Hugging Face zip), a yfinance news snapshot and the Finnhub news days needed by the sampled set-C decisions. It also checks that the Kaggle CSVs are in place.
  - `src/data/cards.py` generates the six data cards above from the files on disk, so no number in them is typed.
- Decisions & why:
  - Finnhub: only the news days for the 300 sampled set-C decisions (seed 42), one UTC day per request. Rejected: the whole year for 8 tickers (about 2,900 requests). One request returns at most ~250 items, so wider requests lose data for busy tickers.
  - Prices keep `close`, `adj_close` and a computed `raw_close`. Rejected: adjusted prices only, which lose the price people actually saw (needed for the memory probe).
  - PhraseBank is read from the original zip. Rejected: adding the `datasets` library; the repo has no parquet export and the zip needs no new dependency.
  - The collector keeps the 15 most recent headlines as planned. Rejected for now: a keyword pre-filter (keep only headlines that name the company). It would widen the news window for busy tickers, but it changes what the relevance filter is tested on. It is kept as a baseline in the relevance eval and as an improvement idea.
- Artifacts: `config.yaml`, `src/config.py`, `src/data/{calendar,finnhub,prices,news,terms,sampling,kaggle,phrasebank,download,cards}.py`, `data/raw/download_summary.json` (not committed), this file.
